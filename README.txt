PRAISE ABIDOYE — COS 106 STUDENT PORTFOLIO

PROJECT STRUCTURE
- index.html       Homepage
- about.html       About Me page
- projects.html    Projects page (3 sample project entries and video)
- planner.html     Interactive academic planner
- contact.html     Contact form with JavaScript validation
- css/style.css    External responsive stylesheet
- js/script.js     Shared JavaScript functionality
- images/          Folder for your own local images

HOW TO RUN
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click index.html and choose "Open with Live Server".
4. Use the navigation menu to test all five pages.

IMPORTANT CUSTOMISATION
1. Replace the sample portrait image URLs with your own photograph.
2. Update your education details if any wording is inaccurate.
3. Replace sample project concepts with actual projects and screenshots.
4. Replace example GitHub destinations with your own repository URLs.
5. Replace the email placeholder on contact.html with your preferred contact details.

FUNCTIONAL NOTES
- Academic Planner: add, complete, delete, filter tasks; tasks persist in localStorage in the same browser.
- Contact Form: validates non-empty fields, email format and digits-only phone number.
- Contact Form is front-end only. It does not send an email.
- Images, Google Fonts and the sample video use internet resources.

COS 106 REQUIREMENT COVERAGE
Homepage: name, photograph, welcome message, navigation and biography.
About: education, aspirations, technical skills, hobbies and interests.
Projects: at least three entries, descriptions, images and links.
Planner: add, complete and delete tasks using JavaScript.
Contact: name, email, phone and message with JavaScript validation.
HTML: semantic elements, forms, table, images, hyperlinks, lists and video.
CSS: external stylesheet, responsive design, Grid, Flexbox, navigation, transitions and consistent colours.
JavaScript: event handling, DOM manipulation, form validation, dynamic updates, arrays, functions and task management.

The two first project entries are illustrative sample concepts, not claims that the projects have already been completed.
